# Reviung41 на SparkFun Pro Micro RP2040

Цель сборки ZMK main: `sparkfun_pro_micro_rp2040//zmk`, shield `reviung41`, snippet `studio-rpc-usb-uart`.

ZMK Studio включена и всегда разблокирована: `CONFIG_ZMK_STUDIO=y`, `CONFIG_ZMK_STUDIO_LOCKING=n`. Подключение по USB к https://zmk.studio/ позволяет менять раскладку без unlock-клавиши. Блокировка после перезапуска, простоя или отключения клиента отсутствует.

Пользовательские файлы находятся в стандартных местах: `config/reviung41.conf` и `config/reviung41.keymap`. Keymap подключает общий `keymap_30.dtsi` из корня репозитория. Локального shield Reviung41 больше нет: матрица, контакты, Kconfig и физические позиции 41 клавиши берутся из встроенного shield ZMK.

Миграция выполнена отдельно в ветке `modernize-reviung41`. Контрольный коммит до миграции: `2401eb9`. Остальные клавиатуры в `config/boards/shields/` пока не перенесены; из-за них ZMK ещё выводит общее предупреждение об устаревшем `config/boards`. Оно не относится к новому расположению Reviung41.

Для RP2040 в `config/controllers/reviung41-rp2040.conf` отключены неподдерживаемые sleep/soft-off и BLE. В локальном keymap `MIDDLE_TRANS` пустой: общий `THUMBS_TRANS` уже содержит пять `&trans`, соответствующих пяти нижним клавишам Reviung41. Общий `keymap_30.dtsi` не изменён.

Результат сборки: `firmware/reviung41/reviung41-sparkfun_pro_micro_rp2040-studio.uf2`. Рядом контрольная сумма и manifest с точными версиями зависимостей. Сборка проверена 2026-10-22; испытания на физической плате не выполнялись.

Для прошивки войти в BOOTSEL-режим RP2040 и скопировать UF2 на диск `RPI-RP2`. Изменения раскладки, сохранённые ранее через Studio, могут переопределять исходную раскладку и после перепрошивки.

Локальная сборка из корня настроенного west workspace:

```sh
west build -s zmk/app -d build/reviung41 -b sparkfun_pro_micro_rp2040//zmk \
  -S studio-rpc-usb-uart -- -DSHIELD=reviung41 \
  -DZMK_CONFIG="$HOME/git/zmk-config/config" \
  -DEXTRA_CONF_FILE='${ZMK_CONFIG}/controllers/reviung41-rp2040.conf'
```

## nice!nano v2: USB + BLE

В `build.yaml` добавлена отдельная цель `nice_nano//zmk` (ревизия 2.0.0 по умолчанию), shield `reviung41`, artifact `reviung41-nice_nano-studio`. Она использует ту же раскладку и всегда разблокированную Studio; USB и BLE включены одновременно. Также включены сон через 6000000 мс простоя и отчёт об аккумуляторе через штатный драйвер nice!nano. Studio имеет USB и BLE транспорты; для BLE использовать нативное приложение.

Настройки разделены на три файла:

- `config/reviung41.conf` — USB, Studio без блокировки, pointing и комбо.
- `config/controllers/reviung41-nice_nano.conf` — BLE, батарея, сон nice!nano.
- `config/controllers/reviung41-rp2040.conf` — USB-only, без сна и soft-off.

В `build.yaml` остаётся один аргумент `EXTRA_CONF_FILE`, выбирающий файл контроллера. `${ZMK_CONFIG}` передаётся в одинарных кавычках: его раскрывает CMake, поэтому путь одинаково работает локально и в GitHub Actions. Общая конфигурация загружается ZMK автоматически. Для локальной сборки nice!nano использовать `-b nice_nano//zmk` и `-DEXTRA_CONF_FILE='${ZMK_CONFIG}/controllers/reviung41-nice_nano.conf'`.

UF2 для nice!nano нельзя прошивать в RP2040 и наоборот. Сохранённые Studio настройки сохраняются при обычной перепрошивке. Для выбора USB/BLE выхода можно назначить `&out OUT_USB` / `&out OUT_BLE` в Studio; профили Bluetooth выбираются через `&bt BT_SEL`.

## Studio: имена, дополнительные слои и Device

Слои 0–9 сохраняют прежние номера, назначения, комбо и тайминги. Добавлены читаемые `display-name` для слоёв и пользовательских behaviors. Русские действия остаются HID-кодами под соответствующую раскладку хоста; Studio не переводит их автоматически в кириллицу.

Новый слой **Device — 10**. Клавиша его активации намеренно не назначена: выбрать в Studio `Momentary Layer` / `To Layer` с номером 10 самостоятельно. При `To Layer` заранее предусмотреть клавишу возврата; на Device нет принудительного перехода на базовый слой.

Расположение на Reviung41 (вид сверху, строки/колонки с нуля):

- R0 C0–C4: Bluetooth-профили 0–4 (в UI могут нумероваться с 1).
- R0 C7: USB output; R0 C8: BLE output.
- R1 C0/C1: предыдущий/следующий BT-профиль.
- R2 C0: очистка сопряжения выбранного профиля.
- R2 C11: вход в загрузчик.
- Остальные назначения прозрачные, нижние клавиши используют общий шаблон прозрачного слоя. BT-действия предназначены для nice!nano; у RP2040 нет BLE.

В конце добавлены три зарезервированных слота **Extra 1–3** (номера 11–13), которые можно включить и переименовать в Studio.

После перепрошивки сохранённые Studio данные могут переопределять исходные назначения и названия. Для полного применения новой исходной раскладки использовать **Restore Stock Settings** в Studio, предварительно сохранив свои изменения: эта операция сбрасывает правки раскладки в Studio. Самостоятельно настройки подключённой клавиатуры не сбрасывались.
